
# Little Village 🧸

Little Village is a full-stack community marketplace designed to help families access free children's essentials.

## About the Project

The goal is to connect parents and caregivers with community members who want to donate items such as baby clothing, strollers, toys, and other necessities.

In the future, Little Village may also support nonprofit organizations and community resource programs.

## Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB (planned)

## MVP Features

- Homepage introducing Little Village
- Browse available donations
- Submit a donation form
- Starter REST API for donation listings
- Responsive layout

## Planned Features

- Smart matching by age and category
- Item request and reservation system
- Community impact dashboard
- Nonprofit organization support
